# Auth Feature

This feature handles all authentication-related functionality including login, signup, and protected routes.

## Directory Structure

- **components/** - Auth-specific UI components (LoginForm, SignupForm, etc.)
- **hooks/** - Custom hooks for auth operations (useAuth, useLogin, etc.)
- **services/** - API services for authentication endpoints
- **types/** - TypeScript types and interfaces for auth data
- **validation/** - Form validation schemas for auth forms

- Context: `src/contexts/AuthContext.tsx` (to be migrated)
- Pages: `LoginPage.tsx`, `SignupPage.tsx`, `AccountPage.tsx`, `ProfilePage.tsx`
