# Dashboard Feature

This feature handles the user dashboard showing progress, statistics, and navigation to different exercises.

## Directory Structure

- **components/** - Dashboard-specific components (StatsCard, ProgressChart, ActivityFeed, etc.)
- **hooks/** - Custom hooks for dashboard data (useDashboardData, useUserStats, etc.)
- **services/** - API services for fetching user progress and statistics
- **types/** - TypeScript types for dashboard data structures

## Related Files

- Pages: `DashboardPage.tsx`
- Services: User tracking backend integration
