# Sheet Music Feature

This feature handles sheet music display and music generation functionality using OpenSheetMusicDisplay.

## Directory Structure

- **components/** - Sheet music components (SheetMusicViewer, MusicControls, etc.)
- **hooks/** - Custom hooks for music rendering (useSheetMusic, useMusicXML, etc.)
- **types/** - TypeScript types for music data and MusicXML

## Related Files

- Pages: `SheetMusicPage.tsx`, `ConverterPage.tsx`
- Services: Music generation backend (Django/Music21)
- Library: OpenSheetMusicDisplay integration
