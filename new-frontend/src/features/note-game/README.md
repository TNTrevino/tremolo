# Note Game Feature

This feature handles the note identification game functionality where students practice recognizing musical notes.

## Directory Structure

- **components/** - Note game UI components (NoteDisplay, GameControls, ScoreTracker, etc.)
- **hooks/** - Custom hooks for game logic (useNoteGame, useGameState, etc.)
- **services/** - API services for note generation and score tracking
- **types/** - TypeScript types for game state, notes, scores, etc.

## Related Files

- Pages: `NoteGamePage.tsx`
- Services: Music generation backend integration
